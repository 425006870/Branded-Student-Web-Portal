# Branded-Student-Web-Portal

# Campus Portal
A simple student web portal built with Django. It has a Home page and an About page that share one layout, navigation, stylesheet, and footer.

# Features
## Reusable base.html with {% extends %}, {% block %}, and {% include %}
## Shared navigation partial (navbar.html)
## Static CSS, fonts, and logo loaded with {% static %}
## Responsive and accessible (skip link, focus outline, high contrast, alt text)

# Run it
## 1. Install Django:
   python -m pip install django
## 2. In the folder that contains manage.py, start the server:
   python manage.py runserver

## 3. Open http://127.0.0.1:8000/ (Home) and http://127.0.0.1:8000/about/ (About).
